# UTP Programación y Algoritmos

## Descripción
Este repositorio reúne ejercicios de lógica, diseño de algoritmos y pseudocódigo desarrollados durante el aprendizaje de programación.

## Objetivos
- Practicar el pensamiento lógico y la resolución de problemas.
- Identificar entradas, procesos y salidas.
- Utilizar variables, operadores, condicionales y ciclos.
- Diseñar, probar y corregir algoritmos.

## Herramientas
- PSeInt
- Diagramas de flujo
- Markdown para documentación
